# Just Dice Show

Concurso de dados en un plató de neón. Rueda los dados deslizando el dedo y suma **exactamente** la cifra del reto en el menor número de pasos.

- Rodar suma la cara de arriba.
- **Combo**: dos números juntos se suman; dos números tocando un dado naranja (+ o ×) hacen su operación, en línea o en diagonal.
- Pierdes si te pasas o te quedas sin pasos.
- 30 niveles con estrellas según lo cerca que quedes del par.

## Jugar

Con GitHub Pages activado, el juego está en `https://akira064.github.io/Dice-Show/`.
Desde el móvil se puede instalar como app («Añadir a pantalla de inicio») y funciona sin conexión.

## Archivos

| Archivo | Para qué |
|---|---|
| `index.html` | el juego completo |
| `manifest.webmanifest` | nombre, icono y pantalla completa al instalarlo |
| `sw.js` | juego sin conexión |
| `icon-*.png`, `apple-touch-icon.png` | iconos |

## APK para Android

Con la web publicada, en [pwabuilder.com](https://www.pwabuilder.com) pega la dirección y elige *Package for stores → Android*.
